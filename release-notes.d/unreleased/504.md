`llm_d_async_async_gate_decisions_total{reason="quota_exhausted"}` now counts only refusals by a quota gate in blocking mode. A saturation gate holding an `overflow`-classified request is counted as `gate_closed`, as the metric's help text always described; previously every refused or parked overflow request was labelled `quota_exhausted` regardless of which gate decided. `pipeline.Verdict` gains an optional `Reason` for gates that want a specific label.
