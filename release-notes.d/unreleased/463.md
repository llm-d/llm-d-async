redis-sortedset: requests sharing a queue and deadline dispatch in submission order. Producers take a per-queue, per-deadline sequence from Redis (`request-seq:<queue>:<deadline>`) in the same script that enqueues the request and stamp it as `EnqueueSeq`; the queue score is `deadline + seq/2^21`, so ordering is strict for the first 2,097,151 submissions per queue and deadline second, after which later ones tie. Scores are no longer whole-second deadlines; anything reading the queue by whole-second score ranges should use an exclusive next-second upper bound.
