The `tier-priority` merge policy no longer stamps the numeric priority header by
default. `priority_header` now defaults to `""` (unstamped) because the old
`x-gateway-priority` default has no consumer in llm-d —
priority reaches them via the InferenceObjective (`objective_header` /
`lane_objectives`) instead. Set `priority_header` explicitly to opt back in.
