Prometheus gates (`prometheus-saturation`, `prometheus-budget`, `prometheus-query`) now log a startup **error** (previously info) when `prometheus-ca-cert` is set without `prometheus-bearer-token-file` while `prometheus-url` targets Google Managed Prometheus (`monitoring.googleapis.com`). This configuration can never succeed — the explicit transport short-circuits GMP's Application Default Credentials and carries no credentials of its own — so gate queries get HTTP 401, gates silently fall back, and the failure is only discoverable after saturation misbehaves. The error explains the two fixes: omit both flags to keep ADC, or also set `prometheus-bearer-token-file`.
