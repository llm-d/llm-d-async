`redis-quota` gate: a go-redis retry of a concurrency slot acquire or release no longer changes the counter twice, and a retried rate-limit admission at the last token is no longer refused. Concurrency mode writes `quota-call:*` keys, so a Redis ACL scoped by key pattern must allow them.
