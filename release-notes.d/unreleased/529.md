`redis`, `redis-quota` and `redis-leased-rate` gates whose `address` matches the `redis-sortedset` transport now reuse the transport's Redis client, so they work against password-protected Redis instead of failing with `NOAUTH`. They use the transport's database: if the transport URL selects a database (for example `/1`) and you write the gate's keys to database 0, write them to the transport's database instead.
