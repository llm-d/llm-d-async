Add the opt-in `gcs_file_multipart` transform for `/v1/audio/transcriptions` and `/v1/audio/translations`. It downloads bounded audio bytes from an allowlisted signed HTTPS GCS URL and sends them as the multipart `file` part. Transient download failures are retried. Explicit producer cancellation or shutdown stops the download. If `--request-timeout` expires while the request deadline is still ahead, the attempt is retried; reaching the request deadline returns `DEADLINE_EXCEEDED`.
