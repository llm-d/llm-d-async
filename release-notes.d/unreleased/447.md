Add a producer-gcp module for GCP Pub/Sub, move Producer to api, and stamp result_route so producers receive only their own results.
The request subscription dead-letters after 100 delivery attempts by default, because the processor Nacks retried requests.
A refusal waits 10 seconds, then Nacks, and that Nack counts as a delivery attempt.
GetResult returns a dead-lettered request as DEAD_LETTERED on a per-route dead-letter subscription, and skips a message it cannot decode.
A gate drop on the Pub/Sub flow, the worker pool, Redis, and SQL still carries result_route when the gate built its own result.
NewProducer rejects an existing request subscription whose dead-letter topic does not match.
producer and producer-gcp need an api tag newer than v1.0.0. Tag them together with make set-version. The in-repo replace directives are not published.
