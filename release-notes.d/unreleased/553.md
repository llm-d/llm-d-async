Prometheus gates (`prometheus-saturation`, `prometheus-budget`, `prometheus-query`) now fail closed at startup when `prometheus-ca-cert` is set without `prometheus-bearer-token-file` while `prometheus-url` targets Google Managed Prometheus (`monitoring.googleapis.com`). With only a CA cert, the explicit transport short-circuits GMP's Application Default Credentials and carries no credentials of its own, so gate queries would get HTTP 401 and silently fall back to their configured fallback (default `0.0`, closed); the processor refuses this configuration at startup instead. The error explains the two fixes: omit both flags to keep ADC, or also set `prometheus-bearer-token-file`. The same guidance is documented on the `prometheus-ca-cert` flag.
