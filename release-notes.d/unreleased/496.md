Merge policies now apply header precedence case-insensitively: a caller header that differs only in casing from a stamped `Content-Type` or queue objective replaces it instead of leaving two keys for the HTTP client to pick between at random, and the fairness, priority and lane-objective stamps replace any casing of the caller's header.
