**Deprecated:** the `redis-pubsub` transport is deprecated. It still works and
will keep working through this release and the next, but it is scheduled for
removal (no earlier than `v0.12.0`, per the N+2 deprecation policy). The
processor now logs a deprecation warning at startup whenever the effective
transport is `redis-pubsub` (including via the default), and the Helm chart
prints the same notice in its install NOTES when the rendered transport is
`redis-pubsub`. Prefer `redis-sortedset` (recommended for production) or
`gcp-pubsub`. No configuration change is required for existing deployments.
