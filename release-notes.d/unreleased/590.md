Response body-transform plugins: a plugin implementing `transform.ResponseTransform` can rewrite a 2xx response body, and optionally its content type, before it is published as a result. Configure them under `responseTransforms` in the `--transform-config-file` file. `transform.BuildChainFromConfig` builds both request and response chains.
