Breaking: `api.Request.ReqPayload()` returns `json.RawMessage` and `RequestMessage.Payload` is a `json.RawMessage`; callers that built a `map[string]any` payload marshal it first. Adds `RequestMessage.Model` and `api.SplitPayload`, `api.JoinPayload`, and `api.AttachPayload`. redis-sortedset producers store each request's payload under its own key, `request-payload:<id>:<token>`, and dispatchers fetch it at dispatch; upgrade dispatchers before producers. Requests queued inline by older producers still dispatch.
