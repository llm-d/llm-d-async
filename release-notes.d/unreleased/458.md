Breaking: `api.Request` gains `ReqModel()`, so every implementation of the interface must add it. `api.Request.ReqPayload()` returns `json.RawMessage` and `RequestMessage.Payload` is a `json.RawMessage`; callers that built a `map[string]any` payload marshal it first. Adds `RequestMessage.Model`, `api.SplitPayload`, `api.AttachPayload`, and the `PAYLOAD_UNAVAILABLE` error code. redis-sortedset producers store each request's payload under its own key, `request-payload:<id>:<token>`, and dispatchers fetch it at dispatch; upgrade dispatchers before producers. Requests queued inline by older producers still dispatch. Run the sorted-set Redis with `maxmemory-policy noeviction`: evicting a payload key ends its request with `PAYLOAD_UNAVAILABLE`.
