Breaking: `api.Request` gains `ReqModel()`, so every implementation of the interface must add it. `api.Request.ReqPayload()` returns `json.RawMessage` and `RequestMessage.Payload` is a `json.RawMessage`; callers that built a `map[string]any` payload marshal it first. The redis-sortedset producer still requires the payload to be a JSON object or `null`, as the `map[string]any` type did, and rejects anything else at submit. Adds `RequestMessage.Model`, `api.SplitPayload`, `api.AttachPayload`, and the `PAYLOAD_UNAVAILABLE` error code. Dispatchers accept payloads stored under their own key, `request-payload:<id>:<token>`, and still dispatch inline payloads from any producer version. The redis-sortedset producer keeps writing payloads inline unless given `producer.WithPayloadKeys()`; enable it only after every dispatcher is upgraded, and run the sorted-set Redis with `maxmemory-policy noeviction`, since evicting a payload key ends its request with `PAYLOAD_UNAVAILABLE`.
