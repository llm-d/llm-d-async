Prometheus gates (`prometheus-saturation`, `prometheus-budget`, `prometheus-query`) now authenticate to Google Managed Prometheus automatically. When `prometheus-url` targets `monitoring.googleapis.com`, gate queries carry GCP Application Default Credentials (e.g. GKE Workload Identity). Previously these URLs received HTTP 401 on every query and the gates fell back to their configured fallback (default `0.0`), keeping the gate closed and blocking dispatch. Explicit `prometheus-bearer-token-file`/`prometheus-ca-cert` auth takes precedence over ADC. Note this is now fail-closed: if `prometheus-url` targets GMP but no usable ADC is available, gate creation fails at startup with an actionable error instead of querying with HTTP 401 forever and silently falling back.
